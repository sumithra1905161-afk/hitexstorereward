# Hitex Spares Loyalty App

A comprehensive loyalty rewards platform for the textile recycling industry with diamond-based rewards system.

## 🚀 Quick Start

```bash
# Frontend
cd frontend && yarn install && yarn start

# Backend
cd backend && pip install -r requirements.txt
```

## 🔗 Portal Links

| Portal | URL | Description |
|--------|-----|-------------|
| Landing Page | `/` | Marketing page |
| User Portal | `/user` | Customer dashboard |
| Admin Portal | `/admin` | Administration |
| Storekeeper | `/storekeeper` | Transaction entry |

## 💎 Diamond System

```
5 Diamonds (💎) = ₹1 INR
Direct Purchase: 15% diamonds
Referral Commission: 10% diamonds
```
